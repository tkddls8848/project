## 작업 4가지

### (1) LINK형 오분류 정정

`openapi_crawler.py:86-93` `_detect_api_type()`:

```python
if 'LINK' in api_type_val:      # CSV가 LINK라고 말함 → 진짜 LINK
    return 'openapi_link'
if swagger_json:
    return 'openapi_new'
return 'openapi_link'           # ← 문제: swagger 추출 실패도 여기로 떨어짐
```

마지막 폴백이 파싱 실패를 진짜 LINK형과 뭉갠다. 현재
`nara_storage/openapi_link/`의 7,643건에 둘이 섞여 있다.

- 두 경우를 구분해 별도 상태(예: `openapi_parse_failed`)로 분리하라.
- 어떤 근거로 그 분류가 나왔는지 레코드에 남겨라 (CSV 표기 / swagger 유무 /
  페이지 구조 중 무엇을 봤는지).
- 새 상태를 추가하면 `file_storage.py`가 폴더를 어떻게 고르는지 확인하되
  **그 파일은 수정하지 말고**, 조정자 배선이 필요하면 `worker_done`에 보고하라.

### (2) 외부 기관 엔드포인트 URL 추출

LINK형의 본질은 "기관이 자기 포털에 따로 두고 data.go.kr에는 링크만 건" API다.
그런데 현재 저장된 레코드의 `목록 URL`은 `https://www.data.go.kr/data/{id}/openapi.do`
— 자기 자신이다. **외부 URL이 통째로 누락돼 있다.**

실제 페이지에는 외부 엔드포인트가 있다. 확인된 예:
`/data/15000017/openapi.do` → `http://openapi.tour.go.kr/openapi/service/TourismAccdtService/getTourismTotqyList`

- 상세 페이지에서 이 외부 URL을 추출해 `CrawlData`에 저장하라.
- 호스트를 별도 필드로도 남겨라 — 후속 작업(T6)이 호스트로 기관 포털을
  클러스터링한다.
- 여러 개일 수 있다. 단수 가정하지 마라.
- **못 찾으면 추정하지 말고 비워두고 근거를 남겨라.**

### (3) JSON-LD 전체 파싱

`file_data_crawler.py:232-264` `_extract_jsonld_download_urls()`가 정규식으로
`contentUrl`과 `encodingFormat` **2개 필드만** 긁는다. 페이지의
`<script type="application/ld+json">`에는 schema.org `Dataset` 전체가 들어 있다.

- `publisher`, `license`, `temporalCoverage`, `contentSize`, `dateModified` 등을
  함께 보존하라.
- **주의**: 기존 주석에 적힌 대로 `description` 필드에 이스케이프 안 된
  따옴표가 자주 들어가 `json.loads`가 깨진다. 관대한 파싱 전략이 필요하고,
  실패 시 기존 정규식 경로로 폴백해 **다운로드 URL 추출은 절대 퇴행시키지 마라.**
- 이 작업은 **추가 네트워크 요청 0회**다. 이미 받은 HTML에서 더 뽑는 것뿐이다.

### (4) 스키마 반영 + 테스트

- `domain/schemas.py`에 위 신규 필드를 반영하라.
- `services/crawler/tests/`에 **네트워크 없이 도는 fixture 기반 테스트**를 추가하라.
  기존 `tests/conftest.py` 패턴을 따른다.
- `nara_storage/openapi_link/`에 실데이터 7,643건이 있다. 읽어서 검증하는 것은
  좋지만 **수정·삭제 금지**.

## 규약

- `find_project_root()` 복제본을 새로 만들지 마라. CLAUDE.md에 4곳 동기화
  제약이 기록돼 있고, 5곳으로 늘리면 안 된다.
- 새 런타임 의존성이 필요하면 `requirements.txt`를 직접 고치지 말고
  `worker_done` 본문에 "필요 패키지: X>=Y"로 보고하라.
- 검증 못 한 것은 `unverified`로 표기한다. 추정을 사실로 쓰지 마라.
- 질문이 생기면 `AskUserQuestion`을 쓰지 마라 (조정자가 볼 수 없다).
  `orca orchestration ask`를 쓰거나, 합리적 가정을 세우고 진행한 뒤
  `worker_done`에 그 가정을 명시하라.

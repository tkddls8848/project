# T2 브리프 — LINK형 상세기능 표를 endpoints[]로 합성 (Phase A)

## 소유 파일
- `services/crawler/crawler/link_spec_builder.py` (신규)
- `services/crawler/infrastructure/nara_parser.py`

## 배경
`nara_storage/openapi_link/`에 7,643건이 있는데 `endpoints`가 비어 있어 검색이
불가능하다. openapi_new(4,171건)보다 많은데 통째로 사장돼 있다.

그런데 **문서 자체는 이미 data.go.kr에 있다.** LINK형 상세 페이지의 상세기능
섹션에 요청/응답 파라미터 표와 샘플 코드가 HTML로 렌더링돼 있다(조정자가 실제
페이지에서 확인함). openapi_new가 인라인 `swaggerJson`으로 주는 정보를 LINK형은
HTML 표로 준다. **따라서 이 작업은 외부 기관 포털을 전혀 건드리지 않는다.**

## 작업
그 표를 파싱해 `nara_parser.extract_endpoints()`가 openapi_new에 대해 내놓는 것과
**동일한 구조**를 합성하라:

```
{method, path, description,
 parameters: [{name, description, required, type}],
 responses: [{status_code, description}],
 tags, section}
```

- `infrastructure/nara_parser.py:23-44`의 기존 `extract_endpoints()`를 먼저 읽고
  출력 형태를 정확히 맞춰라. 검색 백엔드가 이 구조를 소비한다.
- 이미 크롤링된 `operation_ids`(`uddi:...`)를 상세기능 단위 식별자로 활용하라.
- **HTTP 메서드나 path를 페이지에서 확정할 수 없으면 추정하지 마라.** 해당 필드를
  `unverified`로 표기하라. 이 저장소는 추정 인용을 금지한다.
- `nara_storage/openapi_link/`의 실데이터로 검증하되 **수정·삭제 금지** (읽기 전용).

## 공통 규약

- 착수 전 `docs/superpowers/plans/2026-08-01-crawler-depth-and-link-harvest.md`를 정독하라.
- **소유 파일 밖은 절대 수정 금지.** 특히 `main.py`, `requirements.txt`,
  `README.md`, `CLAUDE.md`, `managers/file_storage.py`는 조정자 소유다.
  배선이 필요하면 직접 고치지 말고 `worker_done` 본문에 보고하라.
- `services/crawler/tests/` 아래 **신규 테스트 파일 생성은 허용**한다.
  네트워크 없이 도는 fixture 기반이어야 한다. 기존 `tests/conftest.py` 패턴을 따르라.
- `find_project_root()` 복제본을 새로 만들지 마라 (CLAUDE.md의 4곳 동기화 제약).
- 새 런타임 의존성은 `requirements.txt`를 고치지 말고 `worker_done`에
  "필요 패키지: X>=Y"로 보고하라.
- 검증 못 한 것은 `unverified`로 표기하라. 추정을 사실로 쓰지 마라.
- `AskUserQuestion`을 쓰지 마라 (조정자가 볼 수 없어 세션이 영구 정지한다).
  질문은 `orca orchestration ask`를 쓰거나, 합리적 가정을 세우고 진행한 뒤
  `worker_done`에 그 가정을 명시하라.

## 이미 완료된 선행 작업 (T1)

`openapi_crawler.py`와 `file_data_crawler.py`는 이미 갱신됐다. 새로 생긴 것:

- `_detect_api_type()`가 이제 `openapi_link` / `openapi_new` /
  `openapi_parse_failed` 셋으로 분류한다.
- `CrawlData.api_type_evidence` — 분류 근거 딕셔너리.
- `CrawlData.external_endpoint_urls` — LINK형 페이지에서 추출한 외부 기관
  엔드포인트 URL 목록.
- `file_data_crawler`의 JSON-LD 파싱이 Dataset 블록 전체를 보존한다.

착수 전 이 3개 파일을 읽어 실제 시그니처를 확인하라. 추측하지 마라.
